# Mis Finanzas — PWA

Aplicación Progressive Web App para control de gastos y deudas.

## 🚀 Instalación
1. Abre el link publicado en GitHub Pages.
2. En Android (Chrome): menú → Instalar app.
3. En iPhone (Safari): compartir → Agregar a inicio.

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript
- Service Worker
- Web Manifest
- GitHub Pages
